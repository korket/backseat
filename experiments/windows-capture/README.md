# Windows capture experiments

Real-desktop tests must be explicitly initiated by a human and stay opt-in.

Close or protect applications containing sensitive information when testing observation, input, or capture against the real desktop. Record observation receipt fields for every capture.

Use only when existing backend behavior leaves a capture question unanswered.

Examples:

- covered-window capture;
- minimized-window behavior;
- DirectX/custom-rendered window behavior;
- capture latency;
- long-running frame stability.
